# Spatio-Temporal-Tumour-Detection

## Overview
This project focuses on tumor growth analysis and detection using deep learning.

## Structure
- `src/`: Core source code for training, prediction, and analysis.
- `notebooks/`: Jupyter notebooks for experimentation and visualization.
- `data/`: (Not uploaded) Dataset for training and evaluation.
- `outputs/`: (Not uploaded) Results and logs.

## Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Place your data in the `data/` directory.

## Usage
Run `python src/main.py` for training or `python src/app.py` for the UI application.
